============================================
SAP (Shift Auto Planner) - Installation AlmaLinux
============================================

PREREQUIS:
- Docker installé
- Docker Compose installé
- Git LFS installé

============================================
ETAPE 1: Installer Git LFS (si pas déjà fait)
============================================
sudo dnf install git-lfs
git lfs install

============================================
ETAPE 2: Cloner le repository
============================================
git clone https://github.com/Vinu1880/Autoplanner.git
cd Autoplanner/planner

# OU si déjà cloné, faire un pull:
cd Autoplanner/planner
git pull
git lfs pull

============================================
ETAPE 3: Charger l'image Docker
============================================
docker load -i sap-image.tar

# Vérifier que l'image est chargée:
docker images | grep sap

============================================
ETAPE 4: Démarrer les conteneurs
============================================
docker-compose up -d

# Vérifier que les conteneurs tournent:
docker ps

# Attendre que sap-db soit "healthy" (environ 30 secondes)

============================================
ETAPE 5: Créer les tables dans la DB
============================================
# Depuis le dossier planner, exécuter:
docker exec sap-app node -e "
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();
prisma.\$executeRaw\`SELECT 1\`.then(() => console.log('DB OK')).catch(console.error);
"

# Si erreur "table does not exist", exécuter les migrations:
# (Depuis votre machine hôte avec Node.js installé)
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/sap" npx prisma db push --accept-data-loss

============================================
ETAPE 6: Accéder à l'application
============================================
Ouvrir dans le navigateur: http://localhost:3000

============================================
COMMANDES UTILES
============================================
# Voir les logs de l'application:
docker logs sap-app -f

# Voir les logs de la base de données:
docker logs sap-db -f

# Arrêter les conteneurs:
docker-compose down

# Redémarrer les conteneurs:
docker-compose restart

# Voir l'état des conteneurs:
docker ps

============================================
EN CAS DE PROBLEME
============================================
1. Vérifier que Docker tourne:
   sudo systemctl status docker

2. Vérifier les logs:
   docker logs sap-app
   docker logs sap-db

3. Redémarrer tout:
   docker-compose down
   docker-compose up -d

4. Si problème de permissions:
   sudo chmod 666 /var/run/docker.sock
